ClearPath 🌱

Your Consent-Gated Co-Pilot for Scholarships and Government Schemes

📌 About the Project

ClearPath is a prototype designed to simplify scholarship and government scheme applications. It helps students prepare applications while keeping them in control of their personal information and actions.

ClearPath follows a consent-first approach: nothing happens without the user's permission.

✨ Key Features

- Scheme Selection: Choose from available scholarship and government scheme options.
- Consent-Based Access: Review individual tasks and allow or skip them.
- Risk Indicators: Tasks are classified as low, medium, or high risk.
- Application Preparation: Helps prepare application details based on permitted information.
- Manual OTP Verification: Users handle OTP verification themselves.
- Privacy Receipt: Shows what information was accessed and what actions were skipped.
- User-Controlled Submission: The user performs the final application submission.

🔒 Privacy and Security

- No action without user permission.
- Sensitive steps remain under user control.
- OTP verification is performed manually.
- A Privacy Receipt provides a record of the session.

🛠️ Technologies Used

🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open "index.html".
4. Right-click and select Open with Live Server.
5. Explore the ClearPath prototype in your browser.
